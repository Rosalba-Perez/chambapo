# Chambapo

Servicios del hogar a domicilio en Cartagena: app Flutter (clientes y prestadores), panel React (administrador), API Django sobre Supabase, y un modelo que predice si una solicitud terminará en contratación.

Lee **GUIA.md** para la estructura de carpetas y el paso a paso de instalación, desarrollo, entrenamiento del modelo y despliegue.
